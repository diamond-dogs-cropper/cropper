# Маршруты

## Реализованы

| URL | Доступ | Layout | Назначение |
| --- | --- | --- | --- |
| `/` | Публичный | `RootLayout` | Лендинг продукта |
| `/login` | Только для гостя | `AuthLayout` | Вход |
| `/register` | Только для гостя | `AuthLayout` | Регистрация |
| `/templates` | Защищённый | `AppLayout` | Список шаблонов организатора |
| `*` | Публичный | `RootLayout` | Ошибка 404 |

Страницы загружаются лениво на уровне маршрута. Layout и обработчик ошибок входят в основной чанк, чтобы навигация и fallback отображались без дополнительного запроса.

## Следующие маршруты

Добавлять их следует вместе с соответствующим пользовательским сценарием, а не заранее пустыми страницами.

| Приоритет | URL | Доступ | Назначение |
| --- | --- | --- | --- |
| 1 | `/templates/new` | Защищённый | Создание шаблона |
| 1 | `/templates/:templateId` | Защищённый | Просмотр результатов и управление шаблоном |
| 1 | `/prepare/:token` | Публичный по токену | Загрузка, кадрирование и скачивание логотипа участником |
| 2 | `/forgot-password` | Только для гостя | Запрос восстановления пароля |
| 2 | `/reset-password/:token` | Только для гостя | Установка нового пароля |
| 3 | `/terms` | Публичный | Условия сервиса |
| 3 | `/privacy` | Публичный | Политика конфиденциальности |

Гостевые маршруты обёрнуты в `GuestOnly`, защищённая ветка — в `RequireAuth`. После входа пользователь возвращается на исходный локальный URL из `?from=`. Публичный `/prepare/:token` не должен требовать аккаунт: это прямо следует из текста на макетах.
